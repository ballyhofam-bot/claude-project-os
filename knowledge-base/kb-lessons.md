# Project File Index

## Naming Convention

Files use prefixes to group by purpose. Claude Projects are flat (no folders), so the prefix IS the folder.

| Prefix | Purpose |
|--------|---------|
| `ref-` | Reference docs read at session start |
| `kb-` | Knowledge base (tribal knowledge, people intel) |
| `log-` | Session logs, decisions |
| `skill-` | Executable command files |
| `tool-` | Interactive artifacts |

## Rules

1. **Nothing gets lost to compaction.** If it matters, it goes in a file.
2. **Session logs append, never overwrite.** New entries at the top.
3. **Knowledge base grows from debriefs.** After every meeting, extract and add.
4. **Decisions are permanent.** Once logged, a decision stands unless explicitly reversed.
